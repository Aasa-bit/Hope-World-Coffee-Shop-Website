# Hope-World-Coffee-Shop-Website

A responsive coffee shop website for **Hope World**, showcasing the brand identity, drink menu, about section, and visual coffee assets.

## Project Structure

* **Main Page (`index.html`):** Core HTML layout, navigation, and page sections.
* **Stylesheets (`css/`):**
  * `bootstrap.min.css`: Bootstrap framework for responsive grid and components.
  * `style.css`: Custom styles, color palette, and layout overrides.
* **Scripts (`js/`):**
  * `bootstrap.bundle.min.js`: Bootstrap interactive components.
  * `jquery-3.7.1.min.js`: jQuery library.
  * `script.js`: Custom interactive behaviors.
* **Media Assets (`imgs/Coffee/`):**

## Running Locally

1. Extract the project archive to a local folder.
2. Open `index.html` directly in any modern web browser.

## Deployment with GitHub Pages

1. Upload the project files (`index.html`, `css/`, `js/`, and `imgs/`) to the root of a public GitHub repository.
2. Navigate to **Settings** > **Pages** in your repository.
3. Under **Build and deployment**, select **Deploy from a branch**, choose the `main` branch and `/ (root)` folder, and click **Save**.
4. Wait a couple of minutes for GitHub Pages to build and publish your live URL.[cite: 1]
